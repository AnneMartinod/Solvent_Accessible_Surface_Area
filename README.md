# Solvent_Accessible_Surface_Area
The goal of this project is to calculate the solvant accessible surface area of a protein. It is based on the the paper : Shrake, A; Rupley, JA. (1973). "Environment and exposure to solvent of protein atoms. Lysozyme and insulin". J Mol Biol 79 (2): 351–71. doi: 10.1016/0022-2836(73)90011-9
